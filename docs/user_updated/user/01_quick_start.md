# 01 — Quick Start Guide

Welcome to the **Cognitive and Memory Support Application**.

This app is designed to provide gentle, structured daily support for people living with early-stage Alzheimer’s disease. It helps with routines, reminders, simple guidance, and caregiver-supported follow-up.

---

## What the App Is For

This app is a **support tool for daily life**. It is not a medical device, and it does not diagnose or treat any condition.

It is intended to help with:

- seeing what needs to happen today
- following routines step by step
- staying connected to important contacts and memory supports
- letting a caregiver help organize reminders, checklists, and progress

---

## Who Uses the App?

The app is built around two main roles.

### 1. Patient
The patient uses the app day to day. The patient-facing screens are designed to stay calmer and simpler, with reminders, checklists, games, and supportive progress summaries.

### 2. Caregiver
The caregiver uses the app to help set up and manage the patient’s support environment. In the current version, caregiver flows focus on managing reminders, checklists, and reviewing progress. Some caregiver capabilities may still be evolving depending on the exact build/version being tested.

---

## Main Features in Plain Language

- **Reminders** — simple prompts for things that need to happen during the day
- **Checklists** — step-by-step guides for routines that are harder to remember
- **Contacts / Memory Aids** — helpful information about important people, where implemented in the current version
- **Games** — light engagement activities, not medical tests
- **Progress** — summaries that help the patient stay encouraged and help the caregiver understand consistency patterns

---

## Arabic and English Support

A major strength of the app is that it supports both **Arabic** and **English**.

The current app is designed so that users can work in the language that feels more natural to them. Arabic support is especially important because many older tools in this space have not handled Arabic well.

In the current version, the main implemented flows are designed to support:

- Arabic text
- English text
- right-to-left layout behavior where appropriate

---

## How to Get Started

1. Open the app and create or sign in to an account.
2. Choose the correct role: **patient** or **caregiver**.
3. If you are linking a caregiver and patient, use the app’s linking/invite flow.
4. Start with a small number of reminders or one checklist rather than adding everything at once.
