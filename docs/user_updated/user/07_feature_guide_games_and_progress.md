# 07 — Feature Guide: Games and Progress

The app includes light games and progress summaries to support engagement and help the caregiver notice patterns.

---

## 1. Games

The current prototype includes simple game experiences such as:

- **Safe Path Memory**
- **Routine Sequence**

These games are intended for **light engagement and gentle cognitive activity**.

### Important

These games are **not** diagnostic tools and should not be treated as medical tests.

A lower score does not automatically mean the patient’s condition is worse, and a higher score does not prove improvement in any medical sense.

---

## 2. Progress

The progress area is meant to summarize patterns such as:

- reminder consistency
- checklist completion
- game participation
- streaks or recent activity where supported in the current version

### Patient view
The patient-facing view should feel encouraging and simple.

### Caregiver view
The caregiver-facing view is intended to be more detailed and useful for understanding patterns over time.

---

## 3. Using Progress Carefully

Progress should be used to understand support needs, not to judge the patient.

Examples of useful questions are:

- Is the current schedule too crowded?
- Are some checklists too long?
- Are some routines easier at different times of day?
- Is the patient engaging with the app regularly?

---

## 4. Current-Version Note

The progress system is one of the most useful parts of the app, but some advanced metrics and visual details may still be evolving in the prototype.

That means a caregiver should treat the progress area as a helpful support tool, not as a perfect finished dashboard.
