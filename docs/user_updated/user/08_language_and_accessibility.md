# 08 — Language and Accessibility

The app is designed to reduce cognitive load and to work in the language that feels most natural to the user.

---

## 1. Arabic and English Support

The app supports both **Arabic** and **English**.

This is important because language comfort can strongly affect how easy the app feels to use.

Arabic support is one of the meaningful strengths of this project, especially because many older tools in similar areas were more limited in Arabic support.

### In the current version
The main implemented flows are designed to support:

- Arabic and English text
- right-to-left layout behavior where appropriate
- a language choice that can be stored in the user profile/settings flow

It is safer to describe this as **strong support in the main implemented flows**, rather than assuming every possible screen or edge case is already perfectly finalized.

---

## 2. Accessibility and Simplicity Principles

The app tries to stay:

- clear
- calm
- simple
- supportive

Examples include:

- larger actions
- simple navigation
- reduced clutter on patient-facing screens
- wording intended to feel helpful rather than alarming

---

## 3. Current-Version Note

As the app grows, new screens still need to be checked for language consistency and layout behavior. So Arabic support is a strong part of the current system, but it should still be validated whenever major new features are added.
