# 10 — Known Limits & Current Version Notes

The Cognitive and Memory Support App is currently built as a **research prototype** for a university bachelor project. 

Because of this, it provides significant supportive functionality, but has some technical limitations you should be aware of during testing and daily use. We want to be completely transparent about what works well and what is still evolving.

---

## What is Supported in the Current Implementation

*   **Arabic/English Support:** The translation and Right-to-Left (RTL) layout systems are implemented and available in the main flows.
*   **The CareLink System:** Caregivers can generate codes, link with patients, and manage basic permissions.
*   **Reminders and Checklists:** You can create, edit, and archive schedules, and they trigger on the patient's device.
*   **Progress Tracking:** The app records actions (Done, Snooze, Skip) and generates streaks and weekly summaries.
*   **Games:** The Safe Path Memory and Routine Sequence games are available to play and record basic scores.

---

## Known Technical Limitations in this Version

### 1. Photo and Video Uploads (Network Limits)
If you add a photo to a checklist or contact, the image is saved to the server. However, if you are testing the app using local Wi-Fi, the second phone might not be able to load the image unless the server is hosted on a public URL. 
*Note: This is a hosting limitation for development testing.*

### 2. Offline Actions
The patient's phone will ring and show reminders even if the Wi-Fi goes down. However, for the app to record that the patient tapped "Done," the phone must currently be connected to the internet. If they tap "Done" while offline, the action may not be saved to the caregiver's progress view.

### 3. Immediate Syncing
When a caregiver adds a new reminder, it does not push instantly to the patient's phone. The patient's phone will download the new schedule the next time the app is opened or synced.

### 4. Invite Codes Do Not Expire
Currently, the 6-letter invite code generated by a caregiver stays valid until it is used. In a future production version, these codes would expire after 24 hours.

### 5. Multi-Day Recurring Reminders
If a patient turns off their phone and leaves it off for a week, they may need to open the app once to "refresh" the schedule when they turn it back on.

---

## A Note on Future Updates
This version is designed to demonstrate that a gentle, caregiver-supported digital environment can work, especially with first-class Arabic support. Future iterations aim to add immediate cloud syncing, offline action saving, and formal app store releases. 

Please use the app as a helpful companion tool, keeping these limitations in mind.
